# 🚀 Landing Page HTML Puro

Esta é a minha **primeira aplicação real** aplicando os conhecimentos de estruturação web absorvidos no início do curso de HTML5 e CSS3 do Curso em Vídeo (Prof. Gustavo Guanabara). 

> 🎯 *O objetivo principal deste projeto foi dominar a semântica do HTML5 antes de introduzir qualquer camada de estilização ou comportamento.*

## 🧠 O que este projeto demonstra?
- **HTML Semântico:** Uso correto das tags de escopo estrutural (`<header>`, `<main>`, `<footer>`) garantindo que o navegador entenda a hierarquia da página.
- **Acessibilidade Base:** Inclusão de textos alternativos (`alt`) em imagens.
- **Formatação de Código:** Uso das tags `<pre>` e `<code>` para exibir trechos de scripts de forma organizada diretamente na tela.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica e limpa, escrita 100% à mão sem o uso de geradores de código.
